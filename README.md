# 个人网站第一版

暖白与苔绿色的个人网站前台，包含首页、作品、文章、摄影相册和收藏。支持浅色与深色模式、响应式布局、页面过渡、相册胶片翻页，以及减少动态效果的系统偏好。

这一版使用示例内容验证视觉与交互。自建内容管理后台尚未接入，当前内容维护在 `dist/content.js` 中。

## 本地运行

在本目录运行 `npm run dev`，然后打开终端输出的本地地址。项目不需要安装第三方运行依赖。

`npm run check` 检查主应用与内容文件的 JavaScript 语法。

## 文件

- `dist/index.html`：页面入口和公共导航。
- `dist/styles.css`：响应式样式、主题和动效。
- `dist/app.js`：页面路由、相册浏览、文章阅读及收藏筛选。
- `dist/content.js`：示例作品、文章、相册和收藏数据。
- `dist/demos/`：可直接体验的两个示例作品。
- `dist/assets/credits.json`：摄影示例的来源记录。

正式内容范围及已确认设计保存在上一级项目的 `docs/design.md` 中。收藏页的当前布局是本轮首版实现，后续可以继续调整。
